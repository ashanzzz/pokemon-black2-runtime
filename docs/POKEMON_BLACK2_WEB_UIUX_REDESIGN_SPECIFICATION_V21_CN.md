# Pokémon Black 2 Web 前端全新 UI/UX 设计规范与设计稿 (V21)

> **版本**：v21.0 · 2026-10-04  
> **代号**：`C-GEAR NEXT // Black 2 Autonomous Command System (B2-ACS)`  
> **定位**：融合合众地区经典 C-Gear 科技感、现代深色赛博战情指挥舱（Cyber-Command Deck）与极简 Apple/Linear 级微交互的高阶自动通关与逆向监控平台。

---

## 一、 设计愿景与核心设计理念

### 1.1 从“调试工具”走向“全自主战情指挥舱”
- **原 UI 痛点**：原有前端以开发调试（DevTools / IDE 风格）为主，大量堆砌只读 JSON 文本与密集面板，缺乏数据层级；战斗、寻路、剧情和背包割裂在不同子页面中，无法一览全局状态。
- **全新定位**：打造**“三维一体”的智能指挥控制台**：
  1. **宏观态势感知**：实时感知合众 615 区块的世界坐标、当前徽章、主线剧情门（StoryGate）阻挡与全通关进度。
  2. **微观战术雷达**：2D 高精实时网格雷达，直观呈现主角、NPC 动态、视野射线、地形高低差与连贯奔跑轨迹。
  3. **实战决策闭环**：对战双方数值可视化看板、Gen 5 全 17 系克制与 STAB 招式期望评分推荐、一键捕获与闭环动作执行。

### 1.2 核心设计哲学 (Core Pillars)
1. **Single Pane of Glass（全景单一视窗）**：最核心的关键指标（当前位置、下一主线目标、队伍血量、输入租赁锁、战况）常驻顶层，一目了然。
2. **Deterministic Confidence & Evidence First（实证确定性高亮）**：所有状态使用统一置信度色彩编码（`Verified` 翠绿 / `Probable` 天蓝 / `Candidate` 橙黄 / `Unresolved` 灰红），绝不掩盖未知。
3. **Fluid Micro-interactions（流体级微动效反馈）**：执行寻路、战斗招式或剧情步进时，按钮具备“准备 -> 锁持有 -> 内存写入 -> 闭环校验（PP/HP/坐标变化）-> 成功光效”的全流程视觉反馈。

### 3.1 页面一：【全景指挥舱】战情总览与主线自驱台 (Overview & Story Runner)

#### 核心功能：
1. **主线里程碑航线轨（Story Milestone Timeline）**：
   - 线性展示合众全境 10 大里程碑（M1 牧场寻狗、M2 基础徽章...到 M8 双龙冰冻徽章、M10 联盟冠军）。
   - 当前正在推进的目标（M8 夏卡）呼吸灯高亮，清晰展示已完成的 6 枚徽章图章。
2. **12 大剧情门态势卡（StoryGate Radar Card）**：
   - 实时列出当前世界中最近的剧情门。例如：
     - `海底隧道 (Zone 120 -> 472)`：🔴 阻挡中（缺少第 7 枚冰冻徽章）。
     - `反转山脉关卡 (Zone 525 -> 120)`：🟢 已解锁放行。
3. **宏观世界路径导引（WorldGraph Macro Route）**：
   - 自动展示当前从立涌市到双龙市的 15 步跨区路线：`Zone 456 -> Zone 448 (立涌码头) -> 轮渡 Ferry -> Zone 379 (飞云市) -> ...`。
4. **一键自驱动步进控制台（Autonomous Controls）**：
   - **【推进下一步 (Step Forward)】**：调用 `/api/v1/agent/story/step`，触发走向码头与水手对话搭乘轮渡。
   - **【前往精灵中心治疗】**：一键规划至最近宝可梦中心，调用已验证的护士 2100 脚本恢复全员 HP/PP。
   - **【全自动主线巡航模式 (Auto-Pilot Switch)】**：开/关无人值守自动推进。

---

### 3.2 页面二：【战术雷达与微观导航】2D 动态雷达与智能寻路 (Tactical Radar)

#### 核心功能：
1. **高精 2D 俯视实时雷达（Interactive Radar Canvas）**：
   - 接入 `/api/v1/navigation/radar/grid`，中心绘制主角点位（带朝向光锥箭头）。
   - 瓦片区分：平地（灰蓝格）、建筑阻挡（高饱和深红/石壁纹理）、草丛遇敌区（荧光绿网格）、水体（深海蓝）。
   - **动态 NPC 标记**：显示周围走动的 NPC 位置及移动方向；针对 NPC 训练家，实时投射出 3~5 格长的红色视线警告光束（Trainer Sight Rays）。
2. **连贯奔跑控制器（Continuous Locomotion Deck）**：
   - **交通模式即时切换**：
     - 🚶 **步行** (Walk)：16 帧/格；
     - 🏃 **跑步** (Run - Hold B)：8 帧/格，平滑连续滑步；
     - 🚲 **自行车** (Bike - Key Y)：4~8 帧/格急速推进；
     - 🏄 **冲浪** (Surf)：水边平滑入水；
     - 🪨 **怪力 / 居合斩 / 飞翔**：秘传技能动作浮动按钮。
3. **点选式点击寻路（Click-to-Move Pathfinder）**：
   - 鼠标在雷达任意可通行瓦片点击，系统实时计算最优 A* 路径，在画布上画出青色连贯光带，并回传坐标下发导航。
   - 若途中 NPC 突然阻挡，雷达立即高亮动态避障路径（Dynamic Re-plan）。

### 3.3 页面三：【对战决策舱】实战状态机与 AI 决策舱 (Combat Deck & Dex)

#### 核心功能：
1. **参战双方超宽动态看板（VS Combatant Header）**：
   - **敌方看板**：物种名称、等级、性别、特性（锐利目光/激流等）、实时 HP 动态血条（绿/黄/红分段动画）、能力阶级（攻/防/特攻/特防/速/命中/闪避，基准 0 阶）。
   - **我方出战宝可梦**：同等全量档案，显示实时剩余 HP/MaxHP。
2. **Gen 5 招式四宫格智能卡（AI Move Cards）**：
   - 渲染 4 个招式卡片（对齐 NDS 4 分区触摸屏布局）：
     - 属性标签（如【水】、【普通】、【超能】）；
     - 威力、命中率、实时剩余 PP；
     - **相克倍率徽章**：`0x` 免疫（灰）、`0.5x` 抵抗（橙）、`1.0x` 正常、`2.0x` 克制（亮绿）、`4.0x` 致命克制（高光紫红）；
     - **STAB 本系加成**：`1.5x STAB` 标识；
     - **AI 综合期望伤害评分（Expected Score）**：算法自动评出的期望收益值。
   - **推荐招式高亮呼吸光圈**：首选最优招式带黄金微光，点击即自动触发闭环使用。
3. **战术动作工具栏（Tactical Action Bar）**：
   - ⚾ **投掷精灵球 (Catch Eval)**：实时展示捕获概率（如 `85.4% 建议捕获`），下拉可选普通球、超级球、高级球。
   - 🏃 **脱离战斗 (Run)**：针对野怪一键撤退（训练家战斗自动置灰）。
   - 🧪 **背包用药 (Use Item)**：伤药、解毒药、活力碎片快捷栏。
   - 🔄 **轮换队员 (Switch)**：快速换出备战宝可梦。

### 3.4 页面四：【全队与背包大厅】精灵全态档案与资源库 (Roster & Inventory)

#### 核心功能：
1. **全队 6 宝可梦立体档案卡（Party Overview Cards）**：
   - 6 个卡片横向网格排列，清晰展示物种、昵称、等级、实时 HP/最大 HP、状态异常图标（麻痹/中毒/濒危）。
   - 4 个已习得技能的实时 PP 环形进度条。
   - 携带道具图标（如丝绸围巾、讲究眼镜）。
2. **背包 5 大口袋仓库检索（Inventory Pocket Explorer）**：
   - 分类标签切换：【道具】(55项)、【回复药】(18项)、【重要道具】(7项，含自行车/探宝器/实况接收器)、【技能机器】、【树果】(6项)。
   - 实时搜索过滤框，支持中英文名称双向即搜即出。
3. **徽章与通关荣誉殿堂（Badges & Hall of Fame Showcase）**：
   - 8 枚合众道馆徽章 3D 质感徽章架（基础、毒性、甲虫、伏特、震动、飞翼已点亮；冰冻、海浪待点亮）。
   - 持有资金计数器：`$294,722`。
   - 名人堂登入次数（CountHallOfFame）与通关状态标签。

### 3.5 页面五：【底层神谕与监控】内存实证与链路审计 (Oracle & Audit Desk)

#### 核心功能：
1. **Block 52 / Block 0 内存十六进制与结构体实时转储**：
   - 交互式 Hex Viewer，高亮金钱（`+0x00`）、徽章掩码（`+0x04`）、名人堂次数（`+0x7C`）。
2. **单一写锁与输入租赁监视器（InputLease Monitor）**：
   - 实时显示当前占用模拟器输入的任务 ID、申请类型（`action:button` / `battle:use_move` / `navigation:step`）、持有时间与队列长度。
3. **事件时间轴流（Event Timeline）**：
   - 实时滚动记录：寻路出发 -> 踏上瓦片 -> 遇敌中断 -> 招式击出 -> PP 减少 1 -> 经验结算 -> 胜利脱战。

## 四、 交互动效与反馈设计规范 (UX & Feedback)

1. **输入执行“微光时序”闭环（Input Execution Ripple）**：
   - 点击任何动作按钮（如“使用招式”或“寻路”）：
     1. **第 0ms**：按钮进入 `executing` 态，显示环形 Spinner，文字变为“下发中…”；
     2. **第 100ms**：顶栏 Lease 指示灯变蓝，标明 `Lease Acquired: battle:use_move`；
     3. **第 400~800ms**：底层回读 RAM 验证成功（PP -1 或目标坐标达成），按钮触发 **0.3s 翠绿光波辉光**；
     4. **异常情况**：若被 NPC 阻挡或处于不可移动状态，按钮触发 **0.3s 琥珀色振动微动效（Shake）**，并在下方弹出明确的拒绝原因 Tooltip。
2. **快捷键系统（Hotkeys Bindings）**：
   - `Space` / `Enter`：执行当前推荐的下一步主线行动（Step Forward）；
   - `1` / `2` / `3` / `4`：战斗中直接释放对应编号的招式；
   - `B`：导航中切换步行 / 奔跑模式；
   - `Y`：一键上下自行车；
   - `C`：快速捕获评估并投掷最优精灵球；
   - `Esc`：紧急中断当前寻路或动作队列。
